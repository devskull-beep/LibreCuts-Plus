# LibreCuts-Plus

(Actualizado)

He añadido una configuración para firmar la APK de release usando un archivo keystore.properties en la raíz del proyecto. También hay un workflow de Actions para compilar y firmar la APK cuando se proporcionen los secretos adecuados.

Por favor, copia keystore.properties.example a keystore.properties y sigue BUILDING.md para generar y subir tu keystore como secreto en GitHub.
